# 顾同学，生日快乐

夜色湖畔的一份生日来信：拆礼物、蛋糕许愿、六页可滑动信笺。

静态 HTML / CSS / JavaScript，无需构建；上传到 GitHub Pages 的 main 分支根目录即可。图片、字体、动画库和音频均使用同目录相对路径。

音乐：进入时尝试播放 Capper《无人区玫瑰》，打开信时切换林俊杰《关键词》。手机浏览器若限制自动播放，首次点击页面或右上角音乐按钮即可开启。关键词音轨已从官方 MV 的 00:21 裁切。

音源参考：[Capper 官方视频](https://www.youtube.com/watch?v=M7ZijOfuhCc)、[林俊杰官方 MV](https://www.youtube.com/watch?v=YFr6p7vB9hc)。音乐和角色权利归原权利人；本页面为个人生日祝福。

画面由 OpenAI 图像工具按夜色湖畔、洋桔梗、粉色信封、帕恰狗蛋糕主题定制。文字使用 Noto Serif SC 字体子集（SIL Open Font License）。GSAP 3.13.0 用于过渡与蜡烛效果。

操作支持触摸横滑、左右按钮、页数圆点与键盘方向键，也支持系统“减少动态效果”。网页不收集表单、没有登录或统计服务。
